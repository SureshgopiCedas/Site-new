CAPP. One way to run every project.

The Controls & Automation Project Platform gives owners, managers and engineers the same structure, the same documents and the same tested building blocks, on every project and every site.

Talk to us about CAPPSee how it works
The problem it solves

A billion possible routes. Every vendor picks their own.

Suppliers, applications, products, specifications, frameworks, methods, software, control and commissioning. Each choice multiplies the options, until one project has around a billion ways to be built.

When every vendor and engineer chooses their own route, you get different software and naming on every line, systems your own team cannot open, and knowledge that walks out of the door at handover.

CAPP replaces those self-selected routes with one proven path, and makes sure what is learned on one project is reused on the next.

Framework

One way to organise projects, phases and documents.

Libraries

Playbook

Step-by-step guides for every phase and every import.

Knowledge & backup

Documentation and backups kept in your company.

The proven path

7 phases. 7 control gates.

A V-Model inspired by GAMP 5. Nothing moves to the next phase until the gate is approved, so scope, quality and changes stay under your control.

CAPP in action

Reuse what is already engineered.

Find a proven library, follow its steps, and store the result for the next project.

  1. Requirement. Start from the need in the user requirements.
  2. Select library. Pick the tested building block that matches.
  3. Read process. Follow the import guide that comes with it.
  4. Import & configure. Bring it into the project and set it up.
  5. Test. Verify against the requirement.
  6. Backup & reuse. Store the result so the next project starts ahead.
