Glossary

Key terms, in plain words.

Control gate
An approval point at the end of a phase. Work does not move on until the gate is signed off.
V-Model
A project model where each design step on the way down is matched by a test step on the way up.
GAMP 5
A widely used industry guide for validating automated systems with a risk-based approach.
URS USER REQUIREMENTS
The document where the owner states what the system must do and how success is measured.
IO-list
The master list of every input and output signal in the project. Build-IT generates code from it.
IEC 81346
An international standard for structuring and naming plant systems and components.
FAT FACTORY ACCEPTANCE TEST
Testing the system at the supplier before it is shipped to site.
SAT SITE ACCEPTANCE TEST
Testing the installed system on site before it is accepted for production.
PLC / HMI
The controller that runs the machine logic, and the operator screens used to run and monitor it.
UDT
User-defined data type: a reusable data structure for a device, such as a motor or valve.
PackML
A standard for machine states and modes, so different machines behave the same way.
S88 ISA-88
A standard for batch control that separates recipes from equipment control.
FAQ

Common questions.

Who are CAPP and Build-IT for?

CAPP is for owners, investors, management and project engineers who want every automation project to follow the same structure. Build-IT is for engineers and technicians on large, IO-heavy projects who want to generate PLC and HMI code from the IO-list instead of typing it.

Do I need both products?

No. Each one works on its own. They are designed to work together: CAPP gives the structure across all 7 phases, and Build-IT speeds up design, build and testing inside that structure.

Which PLC and HMI platforms are supported?

Siemens TIA Portal V18 and WinCC, and Rockwell Studio 5000 and FactoryTalk View SE. More platforms are planned. Tell us what you use.

Will we depend on you after the project?

No. The whole idea is that the system and the knowledge stay in your company. Libraries, documentation and backups are yours, so your own team can run and extend the system.

Can we use CAPP with our existing vendors?

Yes. CAPP gives every vendor the same playbook, naming and libraries, so they work to your standard instead of their own.
